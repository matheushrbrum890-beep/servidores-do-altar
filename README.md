# Servidores do Altar — Plataforma de Formação Litúrgica

Site estático pronto para GitHub Pages.

## Recursos
- Página inicial responsiva
- Menu lateral por módulos
- Pesquisa de conteúdo
- Vídeos do YouTube incorporados
- Progresso dos módulos com localStorage
- Favoritos
- Modo claro/escuro
- Quiz com 10 questões
- Área do Ano Litúrgico
- Área preparada para materiais
- Links de apoio
- Funciona no celular
- Não exige banco de dados ou servidor

## Publicar no GitHub Pages
1. Crie um repositório no GitHub, por exemplo `servidores-do-altar`.
2. Envie todos os arquivos desta pasta para o repositório.
3. Abra Settings → Pages.
4. Em Source, selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde o GitHub Pages publicar.

## Próxima evolução
